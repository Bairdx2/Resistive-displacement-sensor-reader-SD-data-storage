### Arduino compatible code useful for measuring displacement of resistive displacement sensors with either 30mm or 38mm plungers. The code was created as part of a project used to characterize the effects of repeated stretching on the properties of epithelial cells ([https://doi.org/10.1115/FEDSM2024-130499](https://doi.org/10.1115/FEDSM2024-130499)).
